# 6th grade math: review list (Oct 26, 2026)

This list has one generated problem for every skill and level, shown the way a **station quiz or unit test** shows it: the story, then each question the test asks, with the right answer in **bold**.

The game makes new problems every time, so these are samples. `npm run check-math` checks thousands of each against independent solvers (see `MATH-CHECK.md`).

Pictures aren't reproduced here. “(picture)” means the problem has one.
